# Industrial Command Center

The desktop build reuses the application's feature routes and renders a compact project command bar, navigation panel, workspace and status strip. The top bar shows the project and target domain. The footer reports the local runtime through the preload bridge. Native Settings opens a compact diagnostics view. Build-time styling selects the desktop theme.

Use deep neutral backgrounds, hard panel boundaries and light text. Copper identifies SearchAnvil and cyan identifies selection and runtime status. Success, warning and critical retain their semantic colors. The shell uses an independently scrolling workspace with compact table rows, tabular numerals and monospaced technical labels. Focus and reduced-motion behavior reuse the application's accessibility rules.

Overview, Issues, Pages, Performance, Comparison and Reports reuse their feature bodies with the new shell and theme. Audits adds crawl launch, cancellation, stage polling, errors and comparison access. Local onboarding and sign-in use desktop wording. Detailed screen-specific redesign, evidence inspector layouts and smaller-window visual review remain open.

## Reference-driven overview

The supplied operations-console reference guides the dark navigation rail, compact top status area, bordered metric strip, central matrix and split findings/activity panels. SearchAnvil's matrix presents Search Health by technical category with a finding count and score meter. The priority queue links to existing issue evidence, and activity displays real crawl states and saved scores. Responsive layouts move the activity panel below priorities and wrap the metric strip in smaller windows.
